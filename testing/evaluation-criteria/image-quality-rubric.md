# Image Quality Rubric

## Overview

This rubric provides a standardized scoring system for evaluating image quality across all dimensions.

---

## Scoring Scale

- **5**: Excellent - Exceeds expectations
- **4**: Good - Meets expectations
- **3**: Acceptable - Meets minimum requirements
- **2**: Poor - Below expectations
- **1**: Very Poor - Fails to meet requirements

---

## Quality Dimensions

### 1. Relevance to Content (1-5)

**Definition**: Image is relevant to and supports the text content.

**Scoring Criteria**:
- **5**: Perfectly relevant, enhances content message
- **4**: Mostly relevant, supports content well
- **3**: Somewhat relevant, partial support
- **2**: Partially relevant, limited support
- **1**: Not relevant, doesn't support content

**Questions to Ask**:
- Does image support content message?
- Does image reinforce key points?
- Does image enhance understanding?
- Is image aligned with content?

---

### 2. Relevance to Product (1-5)

**Definition**: Image reflects product type, industry, and audience.

**Scoring Criteria**:
- **5**: Perfectly reflects product context
- **4**: Mostly reflects product context
- **3**: Somewhat reflects product context
- **2**: Partially reflects product context
- **1**: Doesn't reflect product context

**Questions to Ask**:
- Does image reflect product type?
- Does image reflect product industry?
- Does image reflect product audience?
- Is image appropriate for product?

---

### 3. Professional Quality (1-5)

**Definition**: Image is professional, high-quality, and usable.

**Scoring Criteria**:
- **5**: Highly professional, excellent quality, publication-ready
- **4**: Professional, good quality, minor improvements possible
- **3**: Acceptable quality, some improvements needed
- **2**: Poor quality, significant improvements needed
- **1**: Very poor quality, not usable

**Questions to Ask**:
- Is image professional?
- Is image high-quality?
- Is image usable without editing?
- Is image publication-ready?

---

### 4. Style Consistency (1-5)

**Definition**: Image maintains consistent style with brand and other images.

**Scoring Criteria**:
- **5**: Highly consistent, matches brand perfectly
- **4**: Mostly consistent, minor variations
- **3**: Somewhat consistent, some variations
- **2**: Partially consistent, significant variations
- **1**: Inconsistent, doesn't match brand

**Questions to Ask**:
- Does image match brand style?
- Is style consistent with other images?
- Are colors consistent (if applicable)?
- Is design approach consistent?

---

### 5. Visual Prompt Quality (1-5)

**Definition**: Visual prompt that generated the image was detailed and relevant.

**Scoring Criteria**:
- **5**: Highly detailed, specific, actionable prompt
- **4**: Mostly detailed, some specifics
- **3**: Somewhat detailed, some vagueness
- **2**: Partially detailed, mostly vague
- **1**: Vague, not actionable prompt

**Questions to Ask**:
- Was prompt detailed?
- Was prompt specific?
- Was prompt relevant to content?
- Did prompt generate appropriate image?

---

## Overall Quality Score

Calculate average of all dimensions:
- **Overall Score** = (Relevance to Content + Relevance to Product + Professional Quality + Style Consistency + Visual Prompt Quality) / 5

### Quality Thresholds
- **Excellent**: ≥ 4.5/5.0
- **Good**: ≥ 4.0/5.0
- **Acceptable**: ≥ 3.5/5.0
- **Needs Improvement**: < 3.5/5.0

---

## Usability Assessment

Assess if image can be used directly:
- **Publication-Ready**: No edits needed (5/5)
- **Minor Edits**: Small tweaks needed (4/5)
- **Some Edits**: Moderate edits needed (3/5)
- **Significant Edits**: Major edits needed (2/5)
- **Not Usable**: Cannot be used (1/5)

---

## Usage Notes

- Use this rubric consistently across all image evaluations
- Score each dimension independently
- Calculate overall score as average
- Document specific examples for each score
- Compare scores across different images
- Use scores to identify improvement areas
