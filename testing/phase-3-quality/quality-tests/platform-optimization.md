# Test Q-004: Platform Optimization

## Test Information

- **Test ID**: Q-004
- **Test Name**: Platform Optimization
- **Quality Dimension**: Platform-Specific Adaptation
- **Priority**: High

---

## Objective

Evaluate platform-specific optimization and format compliance:
1. Content format matches platform requirements
2. Content length is appropriate for platform
3. Content style matches platform best practices
4. Content is optimized for platform audience
5. Platform-specific features are used correctly

---

## Prerequisites

- User account created and logged in
- At least one product created
- Content generated for multiple platforms:
   - LinkedIn
   - Twitter
   - Blog
   - Instagram (if applicable)

---

## Test Steps

### Step 1: Generate Content for Each Platform
1. Use same insight
2. Generate content for:
   - LinkedIn post
   - Twitter thread
   - Blog post
   - Carousel (if applicable)

**Expected Result**: Content generated for all platforms

---

### Step 2: Evaluate LinkedIn Optimization
1. Review LinkedIn post
2. Assess:
   - [ ] Length is appropriate (200-500 words)
   - [ ] Style is professional and thoughtful
   - [ ] Format is optimized for LinkedIn
   - [ ] Can be longer form if needed
   - [ ] Value-driven content

**Expected Result**: LinkedIn content optimized correctly

---

### Step 3: Evaluate Twitter Optimization
1. Review Twitter thread
2. Assess:
   - [ ] Each tweet ≤ 280 characters
   - [ ] Thread structure is clear
   - [ ] Style is concise and punchy
   - [ ] Engaging and hook-driven
   - [ ] Format follows Twitter best practices

**Expected Result**: Twitter content optimized correctly

---

### Step 4: Evaluate Blog Optimization
1. Review blog post
2. Assess:
   - [ ] Length is appropriate (800-1500 words)
   - [ ] Structure is clear (headings, paragraphs)
   - [ ] Content is in-depth and valuable
   - [ ] SEO-friendly (if applicable)
   - [ ] Well-organized

**Expected Result**: Blog content optimized correctly

---

### Step 5: Evaluate Carousel Optimization
1. Review carousel content
2. Assess:
   - [ ] Multiple slides with clear structure
   - [ ] Visual-first approach
   - [ ] Each slide is concise
   - [ ] Flow is logical
   - [ ] Visual prompts are provided

**Expected Result**: Carousel content optimized correctly

---

### Step 6: Compare Platform Adaptations
1. Compare same insight across platforms
2. Assess differences:
   - [ ] Format adapts to platform
   - [ ] Length adapts to platform
   - [ ] Style adapts to platform
   - [ ] Content is platform-appropriate

**Expected Result**: Content clearly adapts to each platform

---

### Step 7: Evaluate Platform-Specific Features
1. Check if platform-specific features are used:
   - LinkedIn: Professional tone, longer form
   - Twitter: Threads, hashtags (if appropriate)
   - Blog: Headings, structure, SEO
   - Carousel: Visual prompts, slide structure

**Expected Result**: Platform-specific features used correctly

---

### Step 8: Test Format Compliance
1. Verify format requirements:
   - [ ] LinkedIn: Appropriate length, professional
   - [ ] Twitter: Character limits, thread format
   - [ ] Blog: Structure, length, SEO
   - [ ] Carousel: Slide structure, visual prompts

**Expected Result**: All formats comply with requirements

---

## Evaluation Criteria

### Platform Optimization Scoring (1-5)

For each platform content, assess:
- **Format Compliance**: [1-5]
  - 5: Perfect format for platform
  - 1: Wrong format

- **Length Appropriateness**: [1-5]
  - 5: Perfect length for platform
  - 1: Wrong length

- **Style Match**: [1-5]
  - 5: Perfect style for platform
  - 1: Wrong style

- **Audience Fit**: [1-5]
  - 5: Perfect for platform audience
  - 1: Doesn't match audience

- **Best Practices**: [1-5]
  - 5: Follows all best practices
  - 1: Doesn't follow best practices

### Success Criteria
- Average platform optimization score ≥ 4.0/5.0
- All formats comply with requirements
- Content clearly adapts to platforms
- Platform-specific features used correctly
