🧠 Cursor Prompt: Message-Driven Image Intelligence Layer

Context

The current image generation system produces generic, people-centric illustrations that do not effectively communicate the message of the content. These images feel like stock visuals and reduce the impact of posts, especially on platforms like LinkedIn and Instagram.

This needs a fundamental redesign.

🎯 Core Goal

Redesign the image generation system so that images communicate a clear message, not just visual decoration.

Images must:

Reinforce the content

Convey meaning at a glance

Be platform-appropriate

Avoid generic “people doing things” visuals by default

🧠 New Core Abstraction: Image Intent

Every image must have an explicit Image Intent, such as:

Explain a workflow

Show before vs after

Visualize a system

Highlight an outcome

Illustrate a concept

Support credibility

Simplify complexity

The system must choose image style based on intent, not randomly.

🧩 Image Categories to Support

The system should support message-driven image types, including but not limited to:

Workflow Diagrams

Step-by-step flows

Arrows, blocks, simple labels

No humans by default

Before / After Comparisons

Side-by-side layouts

Clear contrast

Minimal text

Conceptual Visual Metaphors

Chaos vs order

Slow vs fast

Manual vs automated

Abstract, clean visuals

Technical / Engineering Abstracts

Architecture blocks

Request flows

Bottlenecks highlighted

Professional, minimal style

Outcome / Impact Visuals

Time saved

Errors reduced

Efficiency improved

Simple charts or numbers

Product UI Highlights

Cropped screenshots

Focused annotations

One key feature at a time

❌ Anti-Patterns to Avoid

The system must actively avoid:

Generic “people working” illustrations

Overcrowded scenes

Random icons without meaning

Images that could fit any SaaS product

Visuals that don’t add information

Humans should only appear when directly relevant, and even then, minimally.

🧠 Decision Flow

The image system must follow this logic:

Audience
   ↓
Content Intent
   ↓
Image Intent
   ↓
Image Category
   ↓
Visual Style


Platform selection comes last.

🏁 Success Criteria

An image is successful if:

The message is clear without reading the post

The image feels intentional, not decorative

The image could not be swapped with a random stock image

The image supports trust and understanding

🧑‍💻 Mindset

Think like:

A product communicator

A systems thinker

A professional LinkedIn content creator

Not like a stock image generator.
